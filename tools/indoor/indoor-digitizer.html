Indoor Digitizer

Pin UTA's evacuation diagrams onto a building's outline, one floor at a time, and trace the hallways, doors, stairs and entrances over them. It saves indoor-edits.json, which npm run import:osm turns into the indoor routing graph.

Draft kept in this browser
How this works
  1. Run npm run fetch:evac. It downloads the diagrams into tools/indoor/cache/evac/. They are copyrighted: they stay on your computer and in this browser, and are never saved to the draft or the repo.
  2. Click a building on the campus map (Nedderman, ERB and Woolf are marked), then Add diagrams and pick every PDF in its folder. Each one is filed under its floor by name.
  3. On each floor, press Use as layout on one diagram per distinct view: one per floor for ERB, one per wing for Nedderman. Diagrams of the same floor differ only in the red dot and the arrows.
  4. Align the layout: click a corner on the diagram, then the same corner of the building outline. Three pairs place it; a fourth shows how well it fits, in meters. Some diagrams draw part of the floor off to one side (ERB's east end, for one): press Use again on the same diagram and align that part separately.
  5. Trace: hallway centerlines (they join where they meet), a door for each room with its number, stairs and elevators (click the same one on the next floor to link them), and the entrances.
  6. Save indoor-edits.json into src/data/, run npm run import:osm, then npm test. The import report's INDOOR section lists anything it could not place.
